Process

This console is not running as administrator, so it can watch the scheduled tasks but not start or stop them. Reopen it as administrator, or run schtasks /end /tn isthislegit-server yourself.
Starts both the chat server and LiveKit — voice is a separate process, so without it text works and calls never connect.
On an installed server these are Windows scheduled tasks that start on boot, and these buttons drive the tasks. Stopping and starting them needs an elevated console; if it says access denied, the message gives you the command to run yourself. In a development checkout they are child processes instead, and closing the console stops them.

Attention

Deployment

This is one decision, not three. It sets the address LiveKit advertises, the address clients are told to reach voice on, and whether Caddy runs. Set separately, those three drift apart — and when they disagree everyone joins the call, the channel shows them in it, and no audio ever arrives.
Stated explicitly rather than detected: a box with several adapters — Ethernet, VirtualBox, Hyper-V — and LiveKit picking the wrong one is silent breakage. Check it with ipconfig.
Two names, because the LiveKit client SDK opens its socket at the root of whatever host it is given. Both point at this connection; Caddy tells them apart by SNI, so it is still one forwarded port.

Server

MB
Voice quality is set here rather than per client, because the bitrate everyone publishes at is what this connection's uplink has to carry. Stereo (studio) means Chromium will not echo-cancel, so it feeds back on speakers — headphones only.

Database

Needed once, on a machine where PostgreSQL is installed but this app's role and database have not been created. The password is used for this one call and never stored. It is the superuser password you chose when installing PostgreSQL — this console cannot install PostgreSQL itself, and nothing here works until it is.

Not done from here

Port forwarding on the router. Nothing on this machine can do it: forward 443/tcp for chat and signalling, and 7881/tcp, 3478/udp and 50000–50100/udp for voice media, which goes straight to this box rather than through Caddy. Do not forward 3000 or 7880 — Caddy reaches both over loopback, and forwarding them republishes the same two services with no TLS in front.

The firewall, which needs an elevated terminal: infra\allow-lan.ps1 -Internet

Secrets are not editable here. They are generated once, by the installer or by hand, and a UI that can rewrite them is a UI that can quietly lock everyone out.
