Stop things

These act on whatever holds the port, so they also clear a server someone left running in another terminal — which Stop above cannot do. Processes are matched by port, never by name, so the console and other Node processes on this machine are never touched. The database is a Windows service (postgresql-x64-17); stopping it needs an elevated terminal.
